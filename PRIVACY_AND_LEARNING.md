# Privacy and Learning Contract

HITFORGE learns locally from accepted songs, edits and explicit teaching.

Learning memory is not the same thing as modifying model weights.

Adapter training is opt-in and should only use examples the user explicitly approves.
Keep adapter versions and provide rollback.

Controls for production:
- Pause Learning
- View Learned Preferences
- Export Learning Data
- Clear Learning Data
- Reset Adapter
- Delete Models

No automatic network upload.
