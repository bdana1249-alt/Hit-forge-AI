# HITFORGE IAML3G3NDZ v0.9

Personal AI Studio for offline songwriting.

### Main workflow
LOAD GGUF → CREATE HIT → STREAM LOCAL GENERATION → ACCEPT & LEARN → TEACH → CREATE AGAIN

No cloud API is required for local generation once a compatible model and native runtime
are installed.

The project does not ship third-party model weights. Verify the license of any model
before using or redistributing it.
