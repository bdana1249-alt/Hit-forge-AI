# HITFORGE IAML3G3NDZ v0.7

Offline-first personal songwriting AI architecture for Android.

Includes:
- native local-LLM bridge
- optional llama.cpp/GGUF integration
- device benchmark
- persistent personal-memory design
- retrieval learning
- versioned LoRA/PEFT adapter plan
- clean/radio/mature/explicit-language/dark/horror/crime-noir modes
- privacy-first local storage

This package does not include third-party model weights or llama.cpp source. Add a reviewed, pinned runtime and a model whose license permits your intended use.
